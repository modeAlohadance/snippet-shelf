# SnippetShelf

Личная библиотека текстовых шаблонов с тегами и подстановкой переменных.

Приложение для Windows с русским интерфейсом, работающее локально без аккаунта и сети.

## Возможности

- Создание, редактирование и удаление шаблонов.
- Поиск по названию, тексту и тегам.
- Переменные вида `{{имя}}`, отдельный предпросмотр результата.
- Копирование результата в буфер обмена.
- Экспорт и импорт JSON: импорт добавляет записи, не заменяя существующие.

## Запуск

Скачайте `SnippetShelf.exe` из [Releases](https://github.com/modeAlohadance/snippet-shelf/releases/latest).
Распаковывать или устанавливать Python для EXE не нужно. Сборка не подписана цифровым сертификатом.

Из исходников: Python 3.10+ с Tcl/Tk, затем `py -3 app.py` или двойной щелчок по `run.bat`.
Для обычного запуска внешние Python-библиотеки не требуются.

## Разработка

```powershell
python -m unittest discover -s tests -v
python app.py --smoke
```

`--smoke` создаёт интерфейс с временным хранилищем и закрывает его; пользовательские данные не меняются.
Для сборки EXE запустите `build.bat`: он создаст локальное виртуальное окружение и установит PyInstaller.
Результат появится в `dist/`. EXE собран для Windows x64.
Владелец репозитория также может запустить Actions → Build Windows release: workflow проверит приложение, соберёт EXE и опубликует новую версию с контрольной суммой. Уже опубликованные версии не перезаписываются.

## Устройство

`core.py`: SQLite, проверка импорта и шаблонизатор без исполнения кода. `app.py`: редактор и окно заполнения.
Данные: `%LOCALAPPDATA%/SnippetShelf/data.sqlite3`, обычная локальная база без шифрования.
Экспорт содержит тексты шаблонов. JSON-импорт и экспорт ограничены 5 МБ и 1000 записями; большую библиотеку можно резервировать копированием `data.sqlite3` при закрытом приложении. Это не менеджер паролей.
Для знакомства импортируйте файл `examples.json` из репозитория — он содержит два примера с переменными.
